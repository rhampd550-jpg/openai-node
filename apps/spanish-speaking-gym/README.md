# Spanish Speaking Gym

A free-first Next.js MVP for practicing Spanish speaking drills, phrases, roleplays, and progress tracking.

## Local environment

Create a local environment file from the checked-in template:

```bash
cp .env.example .env.local
```

The current MVP does not require paid APIs, authentication, or a cloud database. `OPENAI_API_KEY` is optional and reserved for future API-backed practice features.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

By default, the app is available at <http://localhost:3000>.
